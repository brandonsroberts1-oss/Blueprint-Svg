# Stroke font credits

The single-line (engraving) fonts in this folder were converted to JSON by
`scripts/build-fonts.mjs` from the SVG fonts distributed in the
[`hersheytext`](https://github.com/techninja/hersheytextjs) package (MIT). Glyph
outlines are unchanged apart from rounding coordinates to whole font units.
